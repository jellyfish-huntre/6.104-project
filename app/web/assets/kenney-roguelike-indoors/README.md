# Kenney Roguelike Indoors sprites

Source: https://kenney.nl/assets/roguelike-indoors
Author: Kenney Vleugels (Kenney.nl)
License: Creative Commons Zero (CC0 1.0), https://creativecommons.org/publicdomain/zero/1.0/

These PNGs come from the pack's transparent tilesheet (16 × 16 px tiles with a 1 px atlas gap). Multi-tile objects are assembled edge to edge so the atlas gaps do not show in Roam:

- `table.png`: columns 0–2, rows 9–10
- `table-green.png`: columns 7–9, rows 9–10
- `chair.png`: column 1, row 2
- `chair-white.png`: column 0, row 8
- `plant.png`: column 16, row 0
- `rug-green.png`: column 24, row 5
- `piano.png`: columns 23–24, rows 8–9
- `cabinet.png`: columns 0–1, rows 12–13
- `shelf.png`: column 20, row 17 (bookcase; the previous crop was a wall segment)
- `candle.png`: column 16, row 6

The original pack contains no walking character animations. Roam draws its animated avatar separately over these sprites.
